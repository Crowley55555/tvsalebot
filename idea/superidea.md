# Супер-идея

## Как надиктовал

Ну смотри, идея вообще, идея бот продажник, бот консультат по продажам телевизора, который заменит человека, который  должен реально отлично продавать телевизоры. возможно даже не только телевизоры для начала телевизоры идея вообще такова сначала сделать логику бота чтобы чтобы можно было продемонстрировать как он продает пока что без каталогов без ничего без может пару каких-то моделей возьмем из каталога, чтобы можно было показать что-то. Так наша задача сейчас заинтересовать клиента, чтобы он заказал у нас разработку этого бота. То есть мы делаем сейчас ядро, которое будет нам заменять продавца-консультанта. Разрабатываем его на модели Gigachat Будем использовать API Gigachat в качестве LLM модели для этого бота Нужно продумать логику и его сценария Вопрос, который он должен задавать, в примеру для телевизоров, это актуально. Размеры комнаты. На каком расстоянии от телевизора будет сидеть человек, чтобы подобрать в сантимаментный, идеальный канал телевизора. В примеру, либо этот самый, для чего телевизор, там для фильма, или для игры, использовать, чтобы можно было реально подбирать телевизор. Для этого надо будет пошариться по интернету, найти отзывы, найти вопросы о любых телевизорах вообще, чтобы из них структурировать промп для продажника, чтобы бот понимал, какие вопросы задавать. В общем, сначала делаем ядро с всей логикой, а потом уже когда если клиент зайдет и он закажет разработку бота, тогда уже будут запихивать в него базы данных телевизоров каталог с ихерным, чтобы он уже обучать бота прямо. и чтобы он по каталогу мог подбирать телевизор для людей.

## Ядро

- **Боль и у кого:** у магазинов электроники (пилотно — продавец Samsung TV) живой продавец-консультант дорог, работает по графику и часто продаёт посредственно; покупатель уходит без покупки или берёт не то.
- **Что система делает вместо нас:** ведёт диалог как опытный продажник — задаёт правильные вопросы (размер комнаты, расстояние до экрана, сценарий: кино/игры/спорт/фон, бюджет) и в финале рекомендует конкретные модели с обоснованием, почему именно они.
- **К какому результату приходит человек:** на этом шаге «человек» — это я и клиент-фирма. Я прихожу к рабочему демо-ядру без каталога (на 3–5 захардкоженных моделях), которое показывает «магию продажи», и получаю заказ на полноценную разработку с интеграцией каталога.
- **Технический выбор:** LLM — Gigachat API, яндекс API, openrouter api; архитектурно — отделяемое ядро, к которому дальше можно прицепить любой канал (Telegram, WhatsApp, веб-виджет).
