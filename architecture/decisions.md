# Журнал решений

> Единая лента архитектурных решений проекта **tvsalebot** (правило П5 из [00-правила-проекта.md](00-правила-проекта.md)).
> Формат строки: `ГГГГ-ММ-ДД — что меняем — почему (ссылка на материал)`.
> Записываем сюда: смену/добавление LLM-провайдера, изменение формата ключей Redis, изменение схем `POST /chat`, добавление нового канала, крупную правку `prompts/system.md`, подключение новой платной внешней услуги, миграции схемы БД.
